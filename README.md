O-Lens — AI-Powered Image Recognition App

A full-stack, Google Lens–inspired application that identifies and analyzes uploaded images using AI-powered models.

🧠 Overview

O-Lens is a web-based platform that allows users to upload images and receive intelligent object detection and classification results — similar to Google Lens.
It uses AI/ML models in the backend and a modern web interface for real-time interaction.

🚀 Key Features

 Image Upload & Detection — Upload any image to identify its content.

 AI-Powered Recognition — Uses advanced image classification models for predictions.

 Backend API — Built with Node.js and Express to handle requests and serve predictions.

 Frontend Interface — Built with React and TypeScript for a smooth, interactive experience.

 Dockerized Setup — Complete development and deployment via Docker Compose.

 Scalable Architecture — Modular design for easy extension and integration.
